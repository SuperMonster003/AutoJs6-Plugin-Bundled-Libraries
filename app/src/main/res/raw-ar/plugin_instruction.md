يوفر Bundled Libraries لسكربتات AutoJs6 مكتبات عددها 13: مكتبات JavaScript مثل axios و cheerio و dayjs, وطبقات توافق Node مثل fs و path. بعد تفعيله تعمل `require('axios')` وغيرها, وكذلك الكائنات العامة مثل `dayjs`, كالمعتاد, فلا تحتاج السكربتات الحالية إلى أي تعديل.

### البدء

1. تأكد من أن هذا المكون الإضافي مفعل في مركز الاضافات في AutoJs6.
2. استخدم `require` لتحميل المكتبة في السكربت, أو استخدم الكائنات العامة `axios` و `cheerio` و `dayjs` و `i18n` و `pangu` مباشرة; انظر الأمثلة أدناه.
3. يمكن إيقاف المكتبات غير المطلوبة في صفحة المكون الإضافي, التي تفتح من مركز الاضافات أو من أيقونة Bundled Libraries على الشاشة الرئيسية.

### الميزات الرئيسية

- **المكتبات**: axios و cheerio و dayjs و i18n و lodash و pangu; ويمكن استخدامها كلها ما عدا lodash مباشرة ككائنات عامة.
- **طبقات توافق Node**: buffer و events و fs و os و path و process و nodejs, وتحمل باستخدام `require`.
- **مفتاح لكل مكتبة**: في صفحة المكون الإضافي مفتاح لكل مكتبة, وكلها مفعلة افتراضيا; والمكتبة الموقوفة لا يمكن تحميلها باستخدام `require`, ولا يمكن استخدام كائنها العام أيضا.

### الاستخدام في السكربتات

يحمل المثال التالي lodash و path باستخدام `require`, ويستخدم الكائنين العامين dayjs و cheerio مباشرة:

```js
var _ = require('lodash');
var path = require('path');

console.log(dayjs(0).valueOf());
console.log(cheerio.load('<p>AutoJs6</p>')('p').text());
console.log(_.map([1, 2], function (x) { return x * 2; }).join());
console.log(path.isAbsolute('/sdcard/Scripts'));
```

عندما يكون المكون الإضافي غير متاح أو تكون مكتبة موقوفة, فإن `require` يرمي خطأ يمكن معالجته هكذا:

```js
try {
    var axios = require('axios');
} catch (e) {
    console.log(e.code, e.library, e.reason);
}
```

- قيمة `code` في الخطأ هي `MODULE_NOT_FOUND`, ويحمل `library` اسم المكتبة و `reason` السبب, مثل `library-disabled` عندما تكون المكتبة موقوفة.
- لا يؤثر المفتاح إلا في استدعاءات `require` اللاحقة; أما الوحدات المحملة من قبل فلا تتأثر.
- تعتمد `fs` على `buffer`, وتعتمد `nodejs` على `process` و `buffer`; فإذا أوقفت مكتبة تعتمد عليها هذه الوحدات تعذر تحميلها أيضا.
- يخدم هذا المكون الإضافي سكربتات JavaScript الافتراضية في AutoJs6; أما السكربتات في المكون الإضافي لبيئة تشغيل Node.js فتستخدم الوحدات المدمجة في Node.js.

### المتطلبات

- Android 7.0 أو أحدث, و AutoJs6 6.8.0 أو أحدث.
- هذا المكون الإضافي مجرد حزمة موارد ولا يحتاج إلى أي أذونات; وطلبات الشبكة في axios يرسلها AutoJs6 الذي يشغل السكربت.

### الأسئلة الشائعة

**السكربت يطلب هذا المكون الإضافي**

بدءا من AutoJs6 6.8.0 لم تعد حزمة AutoJs6 تتضمن هذه المكتبات. ثبت هذا المكون الإضافي وفعله في مركز الاضافات, وتأكد من أن مفتاح المكتبة المطلوبة مفعل في صفحة المكون الإضافي.

**السكربتات الحالية**

لا تحتاج إلى تعديل. الكائنات العامة مثل `axios` والاستدعاءات مثل `require('axios')` تعمل كما هي, وتحمل المكتبات من هذا المكون الإضافي.
