Bundled Libraries предоставляет скриптам AutoJs6 13 библиотек: библиотеки JavaScript, например axios, cheerio и dayjs, а также прослойки совместимости с Node, например fs и path. Если плагин включён, `require('axios')` и другие, а также глобальные объекты вроде `dayjs` работают как обычно, поэтому существующие скрипты менять не нужно.

### Начало работы

1. Убедитесь, что этот плагин включён в Центре плагинов AutoJs6.
2. Загрузите библиотеку в скрипте через `require` или используйте глобальные объекты `axios`, `cheerio`, `dayjs`, `i18n` и `pangu` напрямую; примеры приведены ниже.
3. Ненужные библиотеки можно отключить на странице плагина, которая открывается из Центра плагинов или значком Bundled Libraries на главном экране.

### Основные возможности

- **Библиотеки**: axios, cheerio, dayjs, i18n, lodash и pangu; все, кроме lodash, можно использовать и напрямую как глобальные объекты.
- **Прослойки совместимости с Node**: buffer, events, fs, os, path, process и nodejs, загружаются через `require`.
- **Переключатель для каждой библиотеки**: на странице плагина у каждой библиотеки свой переключатель, по умолчанию все включены; отключённую библиотеку нельзя загрузить через `require`, и её глобальный объект тоже недоступен.

### Использование в скриптах

Пример ниже загружает lodash и path через `require` и напрямую использует глобальные объекты dayjs и cheerio:

```js
var _ = require('lodash');
var path = require('path');

console.log(dayjs(0).valueOf());
console.log(cheerio.load('<p>AutoJs6</p>')('p').text());
console.log(_.map([1, 2], function (x) { return x * 2; }).join());
console.log(path.isAbsolute('/sdcard/Scripts'));
```

Если плагин недоступен или библиотека отключена, `require` выбрасывает ошибку, которую можно обработать так:

```js
try {
    var axios = require('axios');
} catch (e) {
    console.log(e.code, e.library, e.reason);
}
```

- У ошибки `code` равен `MODULE_NOT_FOUND`, в `library` указано имя библиотеки, в `reason` причина, например `library-disabled`, если библиотека отключена.
- Переключатель влияет только на последующие вызовы `require`; уже загруженные модули он не затрагивает.
- `fs` зависит от `buffer`, а `nodejs` от `process` и `buffer`; если отключить библиотеку, от которой они зависят, их тоже нельзя будет загрузить.
- Этот плагин предназначен для обычных скриптов JavaScript в AutoJs6; скрипты в плагине среды выполнения Node.js используют встроенные модули Node.js.

### Требования

- Android 7.0 или новее и AutoJs6 6.8.0 или новее.
- Плагин является только пакетом ресурсов и не требует разрешений; сетевые запросы axios отправляет AutoJs6, который выполняет скрипт.

### Частые вопросы

**Скрипт сообщает, что нужен этот плагин**

Начиная с AutoJs6 6.8.0, пакет AutoJs6 больше не содержит эти библиотеки. Установите плагин, включите его в Центре плагинов и убедитесь, что на странице плагина переключатель нужной библиотеки включён.

**Существующие скрипты**

Менять их не нужно. Глобальные объекты вроде `axios` и вызовы вроде `require('axios')` продолжают работать, а библиотеки загружаются из этого плагина.

Версии, имена модулей и лицензии библиотек указаны на [странице проекта](https://github.com/SuperMonster003/AutoJs6-Plugin-Bundled-Libraries).
