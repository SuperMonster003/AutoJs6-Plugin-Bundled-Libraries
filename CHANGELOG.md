# Changelog

## v1.0.0 (unreleased)

### feature

- axios, cheerio, dayjs, i18n (with banana-i18n), pangu and lodash for require and the global objects of AutoJs6 scripts, moved out of the AutoJs6 APK (files as in AutoJs6 6.8.0)
- Node compatibility shims buffer, events, fs, os, path, process and nodejs for require in AutoJs6 scripts
- Launch page with one switch per library (default on), in two sections: libraries and Node compatibility shims

---

## v1.0.0 (未发布)

### 新增

- axios, cheerio, dayjs, i18n (含 banana-i18n), pangu 与 lodash, 供 AutoJs6 脚本的 require 与全局对象使用, 由 AutoJs6 APK 迁出 (文件同 AutoJs6 6.8.0)
- Node 兼容垫片 buffer, events, fs, os, path, process 与 nodejs, 供 AutoJs6 脚本 require 使用
- 启动页按库提供开关 (默认开启), 分为 "库" 与 "Node 兼容垫片" 两节
